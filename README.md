# Srinidhi A.R. — Personal Portfolio

This repository contains the source code for the personal portfolio website of **Srinidhi A.R.**, Founder of Focal Town and seasoned Real Estate Sales & Marketing Professional in Bengaluru, India.

## About The Project

- **Founder & Strategist:** Srinidhi A.R.
- **Venture:** Focal Town (Real Estate Sales & Marketing)
- **Key Milestones:** 0.5M+ sq. ft. of real estate space sold, 15+ years of industry experience.
- **Stack:** [Next.js](https://nextjs.org/) (App Router), [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/).
- **Design:** Editorial architectural direction (*Cobalt on Sand*) created with Taste Skill.

## Getting Started

To run this website locally on your computer:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Sections Included

- **Hero / Waterline Headline:** Executive overview and key metrics.
- **About Me:** Professional history across Brigade Group, Assetz, Gowri Construction, and Focal Town.
