- **Name:** A.R. Srinidhi

- **Key Milestones:** 0.5M+ sq. ft. of real estate space sold, 15+ years of industry experience.
- **Stack:** [Next.js](https://nextjs.org/) (App Router), [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/).
- **Design:** Dark luxury architectural aesthetic inspired by harshith.com (Obsidian Ink, Warm Bone, Antique Gold, Deep Wine).

## Getting Started

To run this website locally on your computer:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

Alternatively, double-click `index.html` in the root folder to view the portfolio instantly in any web browser without needing terminal commands.
